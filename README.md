# Clinic-Appointment-Tracker

A console-based Dart application developed as a midterm project ("The Dart App Simulator") simulating a Philippine Health Clinic Appointment and Patient Management System.

## Features
- **Object-Oriented Programming (OOP)**: Utilizes a base `User` class, a derived `Patient` subclass with inheritance, the `Reportable` abstract interface, and a reusable `LoggerMixin`.
- **Asynchronous Operations**: Uses `Future`, `async`, and `await` to simulate network connectivity and backend database processing delays.
- **Error Handling**: Implements `try-catch` blocks and null-safety operators (`??`) to handle user input safely and prevent runtime crashes.

## How to Run
1. Ensure the Dart SDK is installed on your system.
2. Open your terminal in the project directory.
3. Run the application using:
   ```bash
   dart run main.dart
